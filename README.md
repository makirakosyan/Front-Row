# Front Row — Mariam Kirakosyan

Editorial portfolio at the intersection of global music, K-pop, and live entertainment.

## Files
- `index.html` — the whole site (single page)
- `images/` — photo assets

## Run locally
Open `index.html` in any browser. No build step.

## Deploy
Drag the folder into Netlify (https://app.netlify.com/drop), or push to a GitHub repo and enable GitHub Pages.
